# HUE — hourofhue.seoul

HUE의 서울 다섯 시간 티 컬렉션을 소개하는 정적 웹사이트입니다.

## 페이지

- `index.html` — 서울 지도형 티 컬렉션, 브랜드 스토리, 스크롤 패키지 컬렉션, 티 리추얼, 첫 블렌드 알림 신청
- `shop.html` — 첨부한 다섯 원본 사진을 16:9로 재구성한 재료 중심 컬렉션 페이지
- `product.html?blend=bukchon` — 다섯 블렌드 공용 상세 페이지
- `tea-finder.html` — 5개 질문으로 오늘의 HUE 차를 추천하고 9:16 공유 카드를 만드는 테스트
- `result.html` — 신청 완료 및 교육용 페이지 안내

## 로컬 미리보기

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. 별도의 빌드 과정이나 외부 패키지가 필요하지 않습니다.

## 제품 상세 URL

- `product.html?blend=bukchon`
- `product.html?blend=seochon`
- `product.html?blend=seongsu`
- `product.html?blend=yeonnam`
- `product.html?blend=haebangchon`

마우스 포인터가 있는 환경에서는 패키지의 전통 매듭을 본뜬 HUE 전용 커서가 표시됩니다. 터치 환경에서는 기본 터치 인터랙션을 유지합니다.

메인 화면에는 서울시의 실제 외곽선을 바탕으로 구 경계선을 없앤 추상 지도가 표시됩니다. 북촌·서촌·성수·연남·해방촌의 실제 위치에는 각 블렌드의 티백 종이택이 놓이며, 누르면 해당 블렌드 상세 페이지로 이동합니다. 지도 외곽은 JUSO 2015 기반 `southkorea/seoul-maps` 공개 데이터(Apache-2.0)를 사용했습니다.

상품 상세 첫 화면은 클릭하면 닫힌 패키지의 양쪽 문이 바깥으로 열리고, 같은 자리에서 각 블렌드의 실제 오픈 패키지 이미지와 내부 티백이 드러납니다. 클릭, 좌우 스와이프, 화살표 키와 화면 버튼으로 열고 닫을 수 있고, 이어지는 상세 구간에서는 재료, 우린 차와 티백, 오픈 패키지 이미지를 순서대로 볼 수 있습니다.

## 오늘의 차 찾기 데이터

질문, 선택지, 차별 점수, 5종 제품 정보, 결과 문구와 결과 예시는 `tea-finder-data.js` 한 파일에서 수정할 수 있습니다. 결과 계산은 총점 → 맛과 향 선호 점수 → 오늘의 기분 점수 → 고정된 차 순서로 동점을 처리합니다. 이름과 이메일은 결과 화면을 여는 동안에만 메모리에 머물며 전송하거나 저장하지 않습니다.

공유 카드는 브라우저에서 1080 × 1920 PNG로 생성됩니다. HTTPS 서비스 주소에서 실행될 때만 카드에 테스트 주소가 포함되고 모바일 기본 파일 공유를 시도합니다. 그 외 환경에서는 이미지 저장과 링크 복사 버튼을 제공합니다.

신청 폼은 교육용입니다. 입력 정보는 서버로 전송하거나 저장하지 않으며, 동의 후 입력값을 지우고 완료 페이지로 이동합니다.

## 개인정보 안내

현재 신청 폼은 입력값을 어디에도 보내지 않습니다. 나중에 Make, Google Sheets, 이메일 등 실제 수집 시스템을 연결할 경우에는 개인정보 안내를 실제 수집 항목, 목적, 보관 기간과 파기 방법에 맞게 반드시 수정해야 합니다.
